# 炒股持仓记账本 (StockTracker)

一个简洁的 Android 炒股交易记录 App：记录每次买入/卖出，自动计算持仓均价、卖出盈亏与浮动盈亏。

## 功能

- **买入记录**：输入单价和数量即可记录，支持多次分批买入，自动计算持仓均价（总成本 ÷ 总数量），价格支持小数点后三位
- **智能卖出匹配**：卖出时按**最低买入价优先**抵扣持仓（先卖最便宜的批次），并自动计算本次交易的实现盈亏
- **T+1 可卖区分**：A 股（沪深京）当日买入的批次自动冻结、次日解锁；港股/美股 T+0 当日即可卖；概览卡显示可卖数量，持仓明细逐批标记"今日买入 · T+1冻结"，卖出时只抵扣可卖批次
- **今日分时**：持仓概览卡分时按钮打开分时图（价格线 + 均价线 + 昨收虚线，红涨绿跌）
- **现价盈亏**：一键刷新实时行情（腾讯接口）或手动输入现价，逐批显示浮动盈亏及百分比；概览卡含现价与当日涨跌幅（红涨绿跌），汇总市值、浮动盈亏与相对持仓均价的收益率
- **账户总盈亏**：主界面汇总各股票总盈亏（浮动盈亏 + 已实现盈亏）及明细，整体红涨绿跌；点击总盈亏条一键并行刷新全部股票行情
- **手续费扣除**：可配置费率（佣金万2.5/最低5元/印花0.05%/过户万0.1），浮动盈亏、已实现盈亏、持仓明细浮盈、单笔卖出净盈亏均扣手续费（买入费按批次分摊、卖出费含印花税），一次性迁移用当前费率重放补算历史手续费，均价仍显示裸价
- **设置与关于**：主题（跟随系统/亮色/暗色）、费率设置、检查更新（GitHub 检测+下载）、开源地址、作者、支付宝打赏、签名指纹校验
- **账户总览**：顶部入口打开环形图，并列标签切换浮盈/市值/已实现占比（红涨绿跌，按数值排序）与全部持仓盘中信号（进入自动刷新、每 30 秒更新、可手动刷新）
- **盘中实时信号（回答"现在能不能买"）**：主界面预测卡 + 分时弹窗横幅 + 总览第 4 标签展示持仓盘中择时信号。基于分钟线纯函数评分（15/30 分钟动量 + 相对板块指数强弱 + 站上均价 + 放量确认），输出 BUY/SELL/HOLD/WATCH/NO_TRADE 与分数、原因。**顶部反转保护**：买入需 15 分钟短动量向上、距日内高点回落 ≥1% 禁买；**追高拦截**：接近日内高点且当日涨幅大/30 分钟涨速快降级观望。时段语义：开盘 30 分钟与午后 13:00–13:30 数据积累中、午休休市、15:00 后已收盘（墙钟兜底防缺行误判）。指数 60 秒缓存、个股 10 秒刷新；指数缺失自动降级标注
- **竞价预测（后台引擎，自动适配）**：每日 9:25 自动聚合推送各 A 股持仓竞价结论。因子：竞价放量（成交额 z-score，乘法放大器）+ 价格抬升 + 板块联动 + 隔夜美股三桶条件概率（学非对称，不硬猜方向）+ 竞价末端上移（9:20 基准→9:25，高权重）。**板块联动自动推荐**：每日 9:25 一条批量请求抓取 100 只候选池（20 行业 × 5 龙头）竞价涨幅，积累 ≥10 天后按竞价涨幅相关性自动推荐 Top6 名单；启动期用名称关键词即时匹配。每只股票独立基线、独立 walk-forward 标定与回测；港股/美股无集合竞价，自动跳过。评分连续量化（含强度×动量交互项、放量趋势情境放大），三目标加权投票（收盘vs开盘为主）；阈值 F1 最大化标定；信心等级 = 历史分数邻域命中率；极值段劣化自适应封顶；合成强度权重/交互强度均纳入 walk-forward 搜索。9:15–9:20 观察区只展示庄家意图参考。三目标分别回填回测
- **交易记录**：完整的买卖历史（含时间、价格、数量、每笔成本、卖出盈亏）
- **数据持久化**：所有数据自动保存到本地（SharedPreferences），重启/重装 App 不丢失
- **单屏界面**：概览、持仓明细、交易记录预览一屏展示；交易、完整历史、现价设置、添加股票等低频操作通过按钮弹窗
- **多股票**：支持同时管理多只股票，数据互相隔离，A 股 / 港股 / 美股 / ETF 代码自动识别；股票标签可一键删除（含全部数据）
- **一键清空**：一键清除所有数据
- 红涨绿跌配色（中国习惯），自动适配深色/浅色模式

## 卖出匹配规则示例

先后买入：5 元 × 200 股、3 元 × 300 股、1 元 × 100 股。

股价上涨后以 **4 元卖出 300 股**：

1. 先抵扣最便宜的 **1 元 × 100 股**（盈利 300 元）
2. 再抵扣 **3 元 × 200 股**（盈利 200 元）
3. 剩余持仓：**3 元 × 100 股** + 5 元 × 200 股
4. 本次交易实现盈利：**500 元**

若此时输入现价 2 元，浮动盈亏为：1 元批次 +100 元、3 元批次 -300 元、5 元批次 -600 元。

## 技术栈

- Kotlin + Jetpack Compose (Material 3)
- ViewModel + StateFlow（无状态 UI 架构）
- Android Gradle Plugin 8.13 / Gradle 9.3
- 腾讯行情接口（qt.gtimg.cn，免费无需 key）自动查询股票名称与现价
- JUnit 4 单元测试（192 个用例，覆盖买入、卖出匹配、T+1、盈亏、持久化、行情解析、竞价预测评分/标定/多股票隔离、盘中信号）

## 构建运行

1. 用 Android Studio（推荐 2024.1+）打开本项目
2. 等待 Gradle 同步完成
3. 连接设备或启动模拟器，点击 Run

命令行构建：

```bash
./gradlew :app:assembleDebug
```

运行单元测试：

```bash
./gradlew :app:testDebugUnitTest
```

APK 输出位置：`app/build/outputs/apk/debug/app-debug.apk`

## 项目结构

```
app/src/main/java/com/example/stocktracker/
├── MainActivity.kt          # 入口 Activity（通知频道 + 每日任务调度）
├── Model.kt                 # 数据模型（批次/交易记录/状态/盈亏计算）
├── StockApi.kt              # 腾讯行情接口（查询名称/现价、市场判断、解析）
├── StockViewModel.kt        # 核心业务逻辑（买入/卖出匹配/盈亏/T+1/持久化/分时信号）
├── PrefsStorage.kt          # 本地持久化（SharedPreferences + JSON）
├── IntradaySignal.kt        # 盘中择时信号纯逻辑（特征/评分/时段/顶部反转与追高护栏）
├── MarketData.kt            # 竞价预测行情抓取（目标/指数/板块名单/100只候选池/美股外围）
├── SectorLearner.kt         # 板块联动自学习（皮尔逊相关/TopK/关键词）
├── SectorResolver.kt        # 板块联动决策链（手选>自动>关键词>内置>兜底）
├── PredictionModel.kt       # 预测数据模型（因子/标准化/记录/统计，按股票隔离）
├── AuctionPredictor.kt      # 纯逻辑：因子→标准化→评分→分类→建议
├── Calibration.kt           # walk-forward 标定（权重网格/经验阈值/信心/封顶/护栏）
├── PredictionEngine.kt      # 预测编排 + 结果回填（按股票独立）
├── PredictionWorkers.kt     # 5 个定时任务（9:18/9:20/9:25/10:00/15:05，循环全部 A 股持仓）+ 调度
├── PredictionNotifier.kt    # 竞价预测本地通知
├── PredictionViewModel.kt   # 盘中信号状态（当前股 + 全部持仓，指数 60 秒缓存 + 竞态防护）
├── SnapshotStore.kt         # 预测数据持久化（快照/阶段/记录）
└── ui/
    ├── StockApp.kt          # Compose 界面（单屏布局 + 弹窗 + 预测卡/信号横幅）
    └── theme/Theme.kt       # 主题与配色
```
