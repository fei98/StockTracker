# 炒股持仓记账本 (StockTracker)

一个简洁的 Android 炒股交易记录 App：记录每次买入/卖出，自动计算持仓均价、卖出盈亏与浮动盈亏。

## 功能

- **买入记录**：输入单价和数量即可记录，支持多次分批买入，自动计算持仓均价（总成本 ÷ 总数量），价格支持小数点后三位
- **智能卖出匹配（策略可切换）**：卖出时默认按**最低买入价优先**抵扣持仓（先卖最便宜的批次），可在卖出弹窗切换为**最高价优先**（先卖最贵的批次，默认最低价，全局偏好记忆），并自动计算本次交易的实现盈亏
- **交易撤销**：交易记录卡片支持“撤销最后一笔操作”，回滚买卖或实际权益登记，同时恢复同轮策略的现金、阶段和占格快照；跨策略起点或缺少快照时提示先关闭策略核对，旧交易数据保留
- **T+1 可卖显示**：A 股（沪深京）当日买入的批次仍按 T+1 在概览卡显示"可卖数量"（可卖数按**券商 T+1 视角**重算：卖出只抵当时可卖批次，避免当日补仓低价被抵用后可卖数虚高）；但**卖出记账不再受 T+1 限制**——可当日买入当日卖出，卖出按最低买入价优先抵扣全部持仓批次
- **今日分时**：持仓概览卡分时按钮打开分时图（价格线 + 均价线 + 昨收虚线，红涨绿跌）
- **现价盈亏**：一键刷新实时行情（腾讯接口）或手动输入现价，逐批显示浮动盈亏及百分比；概览卡含现价与当日涨跌幅（红涨绿跌），汇总市值、浮动盈亏与相对持仓均价的收益率；现价弹窗可输入**目标盈利额**反推对应期望现价并一键设为现价
- **账户总盈亏**：主界面汇总各股票总盈亏（浮动盈亏 + 已实现盈亏）及明细，整体红涨绿跌；点击总盈亏条一键并行刷新全部股票行情
- **手续费扣除**：可配置费率（佣金万2.5/最低5元/印花0.05%/过户万0.1），浮动盈亏、已实现盈亏、持仓明细浮盈、单笔卖出净盈亏均扣手续费（买入费按批次分摊、卖出费含印花税），一次性迁移用当前费率重放补算历史手续费，均价仍显示裸价
- **仓位跟随 v3**：每股独立设置成本上下限、目标交易金额、百分比步长、固定参考价及可用现金；正向跌买涨卖，成交触边进入反向，反向回到中线恢复正向。阶段、固定格子、资金与占格持久化，部分卖出不释放格子；整笔建议允许越过成本阈值，但现金、盈利批次或T+1可卖量不足则等待。实际记账后推进阶段，撤销同步恢复。002396推荐配置仅由按钮主动填入，所有值仍可编辑，不自动覆盖旧设置。旧策略原参数保留，确认资金与新起点后启用。[详细规则与手机验收清单](POSITION_FOLLOWING_MODEL.md)
- **手动权益登记**：在策略详情登记券商实际净现金、转增股数、公告价格参考参数及除权后现价；保持原始总成本与未摊买入费、允许零股占格、仿射调整网格并重新定位。实际分红与扣税进入日/月/年收益；不自动猜公告或潜在红利税。
- **已触发汇总**：总览第三个标签汇总当前现价已达到上涨或下跌操作价的股票，显示现价、触发方向、操作价与买卖股数，点击跳转对应股票首页。进入标签自动刷新一次全部行情，也可手动刷新；未配置提醒、现价无效或操作点无效的股票不参与，行情不再满足条件时移出列表，不保留历史触发状态。
- **总览导航**：本次应用会话记住上次选中的总览标签，离开后返回继续显示并自动滚到对应标签；不写入本地存储，应用进程重新启动后默认浮盈。交易汇总中的整条记录可点击，按市场和股票代码跳转到对应股票首页。
- **设置与关于**：主题（跟随系统/亮色/暗色）、费率设置、检查更新（GitHub 检测+下载）、开源地址、作者、支付宝打赏、签名指纹校验
- **底部导航**：首页 / 总览 / 我的 三个主 tab；总览为全屏页，横向滑动标签切换浮盈/市值/已实现/交易汇总/股数占比（红涨绿跌，按数值排序）与全部持仓周趋势预测（进入自动刷新、可手动刷新），交易汇总为全部股票交易记录合并、按时间倒序（最新在上），标签可任意增删、超出屏幕可横滑且箭头提示方向；「浮盈」为正的持仓在股票名后标注可卖提示（全部可卖不标记 / 部分可卖标「部分可卖」/ 都不可卖标「不可卖」，对应 T+1 冻结状态）；「已实现」为同花顺风格收益统计：日收益 / 月收益 / 年收益三档 chip 切换视图（chip 显示标签+当前值），选择器常驻于饼状图上方（日收益为完整日历、每一天标当日收益；月收益为最老月份至当前月连续列表；年收益为第一笔交易年份至今），选中后展示该期总收益大数字 + 各股票收益饼状图与占比，数据区可整体下滑；「我的」为微信式列表页（设置 / 关于，支持逐级下钻与系统返回手势）
- **未来一周趋势预测（回答"未来一周向上还是向下"）**：首页预测卡 + 总览第 2 标签展示 A 股持仓的未来 5 个交易日方向预测。基于日K线（腾讯 fqkline 前复权）纯函数评分：20/60 日动量 + 价格 vs MA20/MA60 + 均线多头/空头排列 + 20 日线斜率 + RSI + 距 60 日高点 + 5/20 日量比 + 连阳/连阴 + 相对指数强弱，输出 看涨/看跌/震荡 + 分数 + 信心（高/中/低）+ 关键因子；walk-forward 前推回测（严格样本外）展示方向命中率与平均 5 日前向收益；日K按天缓存，多日维度不做高频刷新；港股/美股暂不支持
- **交易记录**：完整的买卖历史（含时间、实际成交价、数量、每笔成本、卖出盈亏），今天的交易标「今天」、昨天的标「昨天」（小字标签）。买入批次是否卖完按已保存的实际抵扣明细判断，兼容最高价/最低价混合卖出；无明细的旧记录回退最低价匹配。只有已完全卖出的买入批次置灰并标注"该批次已卖完"；卖出记录正常显示，不标注整只股票已清仓。
- **数据持久化**：所有数据自动保存到本地（SharedPreferences），重启/重装 App 不丢失
- **单屏界面**：首页概览、持仓明细、交易记录预览一屏展示；交易、完整历史、现价设置、添加股票等低频操作通过按钮弹窗
- **多股票**：支持同时管理多只股票，数据互相隔离，A 股 / 港股 / 美股 / ETF 代码自动识别；顶部下拉选择器切换股票（股票多时无需横向滑动，点开即见全部），持仓概览卡支持左右滑动快速切换相邻股票（联动下方预测/明细/记录），下拉菜单中可一键删除（含全部数据）
- **一键清空**：一键清除所有数据
- 红涨绿跌配色（中国习惯），自动适配深色/浅色模式

## 卖出匹配规则示例

先后买入：5 元 × 200 股、3 元 × 300 股、1 元 × 100 股。

股价上涨后以 **4 元卖出 300 股**：

1. 先抵扣最便宜的 **1 元 × 100 股**（盈利 300 元）
2. 再抵扣 **3 元 × 200 股**（盈利 200 元）
3. 剩余持仓：**3 元 × 100 股** + 5 元 × 200 股
4. 本次交易实现盈利：**500 元**

若此时输入现价 2 元，浮动盈亏为：1 元批次 +100 元、3 元批次 -300 元、5 元批次 -600 元。

## 技术栈

- Kotlin + Jetpack Compose (Material 3)
- ViewModel + StateFlow（无状态 UI 架构）
- Android Gradle Plugin 8.13 / Gradle 9.3
- 腾讯行情接口（qt.gtimg.cn，免费无需 key）自动查询股票名称与现价
- JUnit 4 单元测试（303个用例，覆盖买卖、费用、撤销、T+1、仓位跟随阶段/固定格子/资金/持久化迁移/过期单/部分成交/分红转增/零股、推荐参数、并发行情顺序，以及行情、周趋势预测、账户总览与导航）

## 构建运行

固定签名与换电脑构建见[SIGNING.md](SIGNING.md)。发布时使用同一份仓库外密钥，不提交签名文件或密码。

1. 用 Android Studio（推荐 2024.1+）打开本项目
2. 等待 Gradle 同步完成
3. 连接设备或启动模拟器，点击 Run

命令行构建：

```bash
./gradlew :app:assembleDebug
```

运行单元测试：

```bash
./gradlew :app:testDebugUnitTest
```

APK 输出位置：`app/build/outputs/apk/debug/app-debug.apk`

## 项目结构

```
app/src/main/java/com/example/stocktracker/
├── MainActivity.kt          # 入口 Activity
├── Model.kt                 # 数据模型（批次/交易记录/状态/盈亏计算）
├── StockApi.kt              # 腾讯行情接口（查询名称/现价、今日分时、日K线）
├── StockViewModel.kt        # 核心业务逻辑（买入/卖出匹配/盈亏/T+1/持久化/分时加载）
├── MarketData.kt            # 行情字段解析、时间戳日期判定、指数基准映射
├── PrefsStorage.kt          # 本地持久化（SharedPreferences + JSON）
├── TradePlan.kt             # Per-stock position thresholds and next trade points
├── WeeklyTrend.kt           # 未来一周趋势预测纯逻辑（特征/评分/分类/walk-forward 回测）
├── WeeklyTrendViewModel.kt  # 周趋势状态（当前股 + 全部持仓，日K按天缓存）
├── Overview.kt              # 账户总览统计（浮盈/市值/已实现/股数、日/月/年收益）
├── FeeConfigStore.kt        # 费率配置持久化
├── SettingsStore.kt         # 主题等设置持久化
├── UpdateChecker.kt         # GitHub 版本检测与下载
└── ui/
    ├── StockApp.kt          # Compose 界面（单屏布局 + 弹窗 + 周趋势卡/总览标签）
    ├── TradePlanUi.kt       # Trade plan settings and signal cards
    └── theme/Theme.kt       # 主题与配色
```
